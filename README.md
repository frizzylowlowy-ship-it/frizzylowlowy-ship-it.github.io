# Dexo

Сайт Dexo Client: главная, вход через Discord, личный кабинет с ключом для лоадера, покупка лицензии (пока только Free) и админ-панель. Статика для GitHub Pages.

## Страницы

- `index.html` — главная с фоном
- `login.html` — вход через Discord
- `cabinet.html` — личный кабинет: UID, логин, группа, даты, Discord ID, HWID, подписка, ключ (копировать / сменить)
- `buy.html` — лицензии (Free, Premium — «скоро»)
- `admin.html` — пользователи (поиск, фильтр, редактирование, блокировка, удаление) и статистика: пользователи, онлайн, скачивания, запуски
- `404.html` — страница «не найдено» для GitHub Pages

## Языки

Русский текст лежит прямо в HTML, английский — в `assets/js/i18n.js` (ключи `data-i18n`). Переключатель в шапке запоминает выбор в `localStorage`. Чтобы добавить текст: пропиши `data-i18n="ключ"` в HTML и перевод в словарь `en`.

## Сейчас это демо-фронт

Бэкенда нет, поэтому `assets/js/store.js` хранит всё в `localStorage` браузера:

- Данные видны только в том браузере, где их создали.
- Вход через Discord — демо: вводишь ник, создаётся аккаунт.
- Пароль админки — `admin` (константа `ADMIN_PASSWORD` в `store.js`). Это не защита, а заглушка.
- «Скачать лоадер» пока только увеличивает счётчик скачиваний.

## Ключи и лоадер

`DB.loaderAuth(key, hwid)` в `store.js` — это то, что будет делать API для лоадера (`POST /api/loader/auth`):

1. ищет пользователя по ключу; неверный/использованный ключ → `invalid_key`
2. заблокирован → `banned`; другой HWID → `hwid_mismatch`
3. при первом входе привязывает HWID
4. засчитывает запуск и **заменяет ключ на новый** — старый больше не работает

В кабинете это можно проверить по ссылке «проверить вход через лоадер».

## Что нужно для продакшена

1. Backend + база (пользователи, ключи, статистика).
2. Discord OAuth2 (`scope=identify`): редирект на `discord.com/oauth2/authorize`, обмен `code` на токен на сервере.
3. Эндпоинт для лоадера с логикой как в `loaderAuth`; онлайн — по пингам лоадера.
4. Настоящая авторизация админки по группе `Admin`.

Название меняется в `SITE_NAME` (`assets/js/layout.js`), в `<title>` страниц и в `assets/js/i18n.js`. Логотип — `assets/img/logo.png`, иконки вкладки — `favicon.png` и `apple-touch-icon.png`. Font Awesome лежит локально в `assets/vendor/fontawesome`.
