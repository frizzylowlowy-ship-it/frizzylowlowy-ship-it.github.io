# Антидроп — антидроп.рф

Образовательная платформа о финансовой безопасности: учит школьников распознавать вербовку в дропперы.
Проект команды «Бетонный файрвол», МБОУ СОШ № 4 г. Большой Камень, хакатон «Дроп.Нет».

## Что внутри

- **Ученикам:** 5 уроков-карточек с вопросами и 8 мини-игр:
  - «Найди флаг», «Опасно или нет?», «Разговор с вербовщиком», «Собери цепочку»;
  - «Деньги пришли по ошибке», «Правда или миф», «Разложи по полочкам», «Реакция: пауза!».
  - Баллы, прогресс и автоматическая грамота за весь курс.
- **Учителям:** 5 готовых занятий: классный час, практикум, урок ОБЗР, родительское собрание, педсовет.
  - Слайды для проектора и интерактивной доски, режим показа и сценарий к каждому слайду с таймингом.
  - PDF слайдов и сценария лежат в `web/public/materials`.
- **Кабинет учителя:**
  - классы, приглашение по ссылке, коду или QR, добавление ученика по логину или телефону;
  - задания с дедлайном;
  - таблица класса: кто в сети, когда был, прогресс, баллы по каждому заданию;
  - карточка ученика с журналом действий;
  - выдача грамот.
- **Родителям:** памятка, тревожные признаки, план «если деньги пришли», как поговорить, чек-лист настроек.
- **Админ-панель:** статистика за 14 дней, пользователи (роль, блокировка, сброс пароля, удаление), все классы.
- **Проверка грамоты** по номеру или QR-коду: `/proverka/AD-XXXXXX`.

## Технологии

- Сайт: React 19 + Vite, framer-motion, шрифты Montserrat и Oswald (локально, в `web/public/fonts`).
- Сервер: Node.js 22+ (встроенный `node:sqlite`), Express. База — один файл SQLite.
- Безопасность:
  - пароли хешируются scrypt, сессии хранятся в httpOnly-cookie;
  - защита от CSRF, ограничение частоты запросов, CSP-заголовки.

## Запуск локально

```bash
cd web && npm install && npm run build      # собрать сайт
cd ../server && npm install
ADMIN_LOGIN=admin ADMIN_PASSWORD='надёжный-пароль' npm start   # http://localhost:8080
npm run seed                                  # (по желанию) демо-класс: demo.uchitel / demo12345
```

Для разработки сайта: `cd web && npm run dev` (запросы `/api` проксируются на :8080).

## Публикация на антидроп.рф

Домен в punycode: `xn--80ailthgfn.xn--p1ai`. Нужен VPS с Ubuntu, DNS-запись A домена должна указывать на IP сервера.

**Вариант 1. Docker**

```bash
git clone <репозиторий> && cd antidrop
docker build -t antidrop .
docker run -d --name antidrop --restart=always -p 127.0.0.1:8080:8080 \
  -v antidrop-data:/data -e ADMIN_LOGIN=admin -e ADMIN_PASSWORD='надёжный-пароль' antidrop
```

**Вариант 2. Без Docker:** установить Node.js 22, собрать сайт, скопировать проект в `/opt/antidrop` и подключить `deploy/antidrop.service`.

**HTTPS и nginx**

```bash
sudo apt install nginx certbot python3-certbot-nginx
sudo cp deploy/nginx.conf /etc/nginx/sites-available/antidrop
sudo ln -s /etc/nginx/sites-available/antidrop /etc/nginx/sites-enabled/
sudo certbot --nginx -d xn--80ailthgfn.xn--p1ai -d www.xn--80ailthgfn.xn--p1ai
sudo systemctl reload nginx
```

Администратор создаётся при первом запуске из переменных `ADMIN_LOGIN` и `ADMIN_PASSWORD`, если в базе ещё нет администратора.

**Резервная копия:** файл `antidrop.sqlite` в каталоге данных (`/data` в Docker).
